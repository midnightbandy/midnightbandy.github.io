Infra Estimator

A free, offline-first estimation platform for India's infrastructure tendering ecosystem, built for a grant application — starting with a working CPWD module.

Vite · React · TSDexie · IndexedDBPython ingestion pipelineInstallable PWA

What it does

Covers CPWD, MoRTH, and Maharashtra PWD estimation workflows, backed by a rate master where every figure traces to a cited government source — the CPWD Detailed Analysis of Rates, the MoRTH Standard Data Book, statutory GST/cess rules — not invented or scraped data.

The verification method is the actual engineering

A citation alone isn't the bar here. For every rate build-up, the app's own calculation engine independently recomputes the rate from its labour/material/machinery components and compares the result against the source document's own published figure. An item that fails that check is excluded and disclosed — never force-included with a citation that doesn't actually check out.

That same discipline runs through the data pipeline: candidates get checksum-gated before they're trusted, failures get written to a report for manual review instead of silently dropped, and every digitisation pass is verified against the previous chapter's already-shipped output before it's trusted not to have broken anything.

Where it stands

Several hundred CPWD rate items digitised with full build-ups, all citation-audited in CI. Coverage grows chapter by chapter — each one gets read against the actual source document, not assumed from a table of contents.

Honest state: this is the one project on this page with nothing to hide behind a "coming soon" — the repo is public, the code is the source of truth, and the citation-audit script runs in CI on every change.
